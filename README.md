# Adaptive BE Toolkit

The purpose of this project is to provide a toolkit for building adaptive backends so that more complex interfaces can be integrated into existing survey frameworks with minimal deviations from intended use patterns.

Several adaptive measures are included and hosted in the toolkit:

- Adaptive Delay Discounting (Agent-based adaptive ED50 determinations)
- Adaptive Purchase Tasks (Agent-based adaptive O<sub>max</sub>/P<sub>max</sub> determinations)

The various measures included can be incorporated into existing survey frameworks via customized iframes with various parameters allowing for customizability.
