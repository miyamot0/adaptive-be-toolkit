# Adaptive Demand Tasks

The **Adaptive Demand Task** is an agent-based, adaptive operant demand procedure. The goal is to efficiently estimate **O_max** (the maximum total expenditure a participant exhibits) and **P_max** (the price at which that maximum expenditure occurs). Rather than presenting a fixed list of prices, the algorithm uses a belief-updating procedure to select the next price point based on the participant's response history, converging on the demand curve's peak expenditure region with a minimal number of trials (default maximum: 20).

## Settings and Parameters

The Adaptive Demand Task can be customized with various settings and parameters to tailor the experience to different research needs. Key parameters include:

- **Reinforcer**: The commodity being purchased (e.g., "Coffee", "Cigarettes").
- **Price Range**: The range of prices presented to participants.
- **Beta**: The adaptation rate, which controls how aggressively beliefs are updated.
- **Max Trials**: The maximum number of trials allowed in the task.
- **Entropy Threshold**: The threshold for belief concentration that can trigger early stopping.
- **Entropy Window**: The number of recent trials considered when calculating the rolling average of entropy drop for stopping criteria.

## Mechanics and Logic

The task presents a binary choice on each trial:

> _"How many \_\_\_\_ would you purchase at a price of `X`?"_

The price `X` is selected adaptively by the algorithm on each trial. After the participant responds, the algorithm updates its internal model of where the indifference point lies and selects the next price accordingly. This continues until a stopping criterion is met.

## Stopping Criteria

The task terminates when one of the following criteria is met:

- **Maximum Iteration**: The default maximum number of trials (20).
- **Regret Min**: The participant's entropy change drops below a certain threshold.
- **Belief Concentration**: The algorithm's belief mass around the estimated indifference point reaches a specified level.

## Output Payload

The task returns the following payload fields:

- `ID`: The unique identifier for the participant/session.
- `MaxExpenditure`: The maximum total expenditure observed across all trials.
- `MaxExpenditurePrice`: The price at which the maximum expenditure occurs.
- `MaxExpenditureQuantity`: The quantity of the reinforcer purchased at the maximum expenditure price.
- `Beta`: The adaptation rate used in the algorithm.

## Example Usage

To use the Adaptive Demand Task, researchers can access it via a URL with participant-specific parameters:

```plaintext
/demand/<participantId>/posm?reinforcer=Coffee&figures=true&debug=true
```

The participant `id` is embedded in the URL path and is echoed back verbatim in the completion payload.
