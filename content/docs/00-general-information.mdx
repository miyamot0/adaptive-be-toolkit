# General Information

The Adaptive BE Toolkit is a browser-based research instrument designed to support the study of decision-making from an operant behavioral economics perspective. It delivers psychometrically adaptive instruments for studying delay discounting as well as operant demand. The toolkit is designed to provide an interface for collecting research information in a manner agnostic to survey platform--something easily embedded into Qualtrics, REDCap, or custom web studies with minimal setup.

## Novel Features and Capabilities

The defining feature of the toolkit is its use of **agent-based adaptive algorithms** for delay discounting and operant demand. Rather than presenting a predetermined sequence of prices or delays (i.e., fixed delays or fixed price lists), each task maintains a probabilistic belief distribution over possible response parameter values (e.g., delays associated with ED50, prices associated with O<sub>max</sub>) and updates that distribution in real time based on participant responses to select the most informative stimulus for each subsequent trial (i.e., "smart" questions).

This dynamic approach yields two practical advantages over fixed procedures:

- **Efficiency.** Reliable estimates of key metrics are obtained in substantially fewer trials. Both tasks generally converge in less 20 questions and provide a means of 'healing' in cases of inconsistent or inaccurate responding. In short, this approach asks fewer questions that are more immediately relevant to the key metrics of interest.

- **Adaptivity.** Stimulus selection is individualized in real time and is not predetermined. The algorithms run locally, without any server infrastructure, and are designed to be robust to a wide range of response patterns. The specific algorithm parameters (e.g., prices ranges, adaptability rates) can be customized by researchers to suit the needs of their specific study population.

## Intended Use Cases

The toolkit is intended for researchers studying behavioral phenomena that depend on deriving metrics central to a reinforcement-based account of decision-making. These include, but are not limited to, sensitivity to commodity price, preference for immediate over delayed rewards, and the patterns of consumption that characterize different populations or conditions. Relevant application areas include:

- **Substance use and addiction research** — Estimating the reinforcing value of substances (e.g., alcohol, tobacco, cannabis) and how that value changes across experimental conditions or treatment stages

- **Consumer and health behavior research** — Measuring hypothetical demand for food, beverages, or health-related commodities as a function of cost

- **Behavioral pharmacology** — Assessing the reinforcing efficacy of drug or non-drug reinforcers across subject groups

- **Intertemporal choice research** — Characterizing individual differences in delay discounting rates and their relationship to impulsivity, substance use, or other behavioral outcomes

The toolkit is **not** a statistical analysis platform. It delivers raw estimates (e.g., O<sub>max</sub>, P<sub>max</sub>, ED50), which would serve as the inputs to downstream analyses and comparisons. Researchers are expected to handle model fitting, group comparisons, and inferential statistics in their preferred analysis environment (R, Python, SPSS, etc.) using the data exported from their survey platform.

Because the measures are embedded in the researcher's existing survey flow, they are easily combined with self-report questionnaires, demographic items, and other instruments in a single session. This strategy was deliberate to minimize complexity while maintaining security and reliability in research. The output fields returned at task completion are plain numeric values or strings that can be stored as embedded data variables alongside all other survey responses.

## Intended User and Analyst

The toolkit is designed to be accessible to researchers who have little or no programming experience. That is, adaptive procedures can be easily incorporated without having to manually design them for specific research purposes. Configuration is handled entirely through URL query parameters. No code needs to be written inside the toolkit itself, and no server needs to be deployed or maintained. Embedding a measure in a Qualtrics or REDCap survey requires only the ability to insert an HTML iframe element and add a short JavaScript event listener to a survey page.

The expected level of technical skill is roughly equivalent to what is already required to use advanced features of common survey platforms: constructing embedded data fields, using piped text to inject response IDs, and adding question-level JavaScript. Researchers comfortable with those tasks should find the integration straightforward.

## Actively Supported Assessment Tools

The toolkit presently supports a total of _two_ adaptive measures of behavioral economic demand and delay discounting.

Two measures are currently included:

- **Adaptive Purchase Task** — Estimates the peak of a work output curve (i.e., response levels alongside demand curves), specifically O<sub>max</sub> (maximum total expenditure) and the associated P<sub>max</sub> (the price at which that expenditure occurs).

- **Adaptive Delay Discounting Task** — Estimates the ED50 indifference point (the delay at which a participant is equally likely to choose an immediate versus a delayed reward).

Both tasks operate entirely within the participant's browser. No server infrastructure is required, and no response data is stored or transmitted by the toolkit itself — all output is returned directly to the host survey platform at task completion. For all intents and purposes, the user essentially never leaves the core survey environment, and the toolkit functions as a seamless extension of the survey platform's existing capabilities.

## Researcher Customization

Researchers can customize the Adaptive BE Toolkit by configuring URL query parameters. These parameters allow researchers to specify task-specific settings such as reinforcer names, price ranges, delays, and more. For example:

- **Reinforcer**: The commodity being purchased (e.g., 'Coffee', 'Cigarettes'). Displayed in question prompts.
- **Price**: The cost presented to the participant for a given quantity of the reinforcer.
- **Quantity / Consumption**: How many units the participant reports they would purchase at the presented price.
- **Expenditure / Revenue**: Price × Quantity — the primary signal the algorithm optimizes around.

These parameters can be overridden by appending them as query parameters to the task URL. For example:

```
/demand/PARTICIPANTID/posm?reinforcer=Coffee
```

For convenience, the toolkit provides a 'Link Builder' interface that allows researchers to generate customized task URLs without needing to manually construct query strings. This interface guides users through the available configuration options and produces a ready-to-use URL for embedding in their survey platform and supports testing to ensure that the algorithm suits their research purposes.

## Survey Platform Integration

The Adaptive BE Toolkit can be easily integrated into existing survey platforms such as Qualtrics, REDCap, and custom web studies. The toolkit operates entirely within the participant's browser, requiring no server infrastructure or data storage by the toolkit itself. Results are returned directly to the host survey platform via the browser's native `postMessage` API, which can be flexibly managed in the host platform's JavaScript environment.

### Example: Qualtrics Integration

To integrate the Adaptive BE Toolkit into a Qualtrics survey, users can follow these general steps:

1. Embed an HTML iframe element in your Qualtrics survey page (e.g., creating a Label element and overriding the base HTML code).

2. Add a short JavaScript event listener to capture the results and post them back to the parent window using `postMessage`.

Example code snippet for Qualtrics integration:

```javascript
// Embed the Adaptive BE Toolkit iframe
const iframe = document.createElement("iframe");

iframe.src =
  "https://example.com/demand/12345?reinforcer=Coffee&priceRange=0-100";
document.body.appendChild(iframe);

// Listen for results and post them back to Qualtrics
window.addEventListener("message", function (event) {
  if (event.origin !== "https://example.com") return;
  const result = event.data;
  Qualtrics.SurveyEngine.setEmbeddedData("O_max", result.MaxExpenditure);
  Qualtrics.SurveyEngine.setEmbeddedData("P_max", result.MaxExpenditurePrice);
});
```

Additional information on customizing and securing these links is provided in later sections of the documentation.
